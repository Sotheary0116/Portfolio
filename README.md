# Lach Theary — Portfolio

A responsive portfolio built with HTML, CSS, and vanilla JavaScript. Open `index.html` directly in a browser, or serve the project folder with any static file server.

## Project structure

```text
index.html
css/style.css
js/script.js
assets/
  images/       Replaceable portrait and project screenshot files
  documents/    Add the real CV PDF here
```

## Personalize the content

- **About text:** Edit the introduction in the `#about` section in `index.html`.
- **Portrait:** Add your own image at `assets/images/profile.jpg`. The placeholder remains visible if the image is absent.
- **Project screenshots:** Put your real screenshots in `assets/images/`, then replace each project's `.project-visual` placeholder in `index.html` with an `<img>` using a relative path. Use the experience evidence slots similarly.
- **Repository and demo links:** Add verified URLs to the `github` and `demo` fields for each project in `projectInfo` in `js/script.js`. The modal only displays links that have a URL.
- **LinkedIn:** Replace the placeholder link in the Contact section of `index.html` with your real profile URL.
- **CV:** Add your actual PDF as `assets/documents/Lach_Theary_CV.pdf`; the navigation and hero buttons already point there. No sample CV is included.

The contact form validates the fields in the browser but does not send messages. Connect a backend or email service to enable delivery.
